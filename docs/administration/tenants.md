# Tenants

A tenant is an organisation sharing the server, a family, a club or a company, with its own libraries, accounts,
groups, settings and security log. Their people never see each other. Only server administrators manage tenants.

**Administration → Tenants**:

- **Add:** type the name of a new tenant. It gets the built-in groups Administrators and Users, and a first library.
  Then make its first administrator in [Accounts](accounts.md), working in that tenant.
- **Work here:** switches your session to that tenant (as the account menu in the top bar does); **Working here** marks the
  current one.
- **Edit:** rename the tenant, disable it (its accounts can't sign in, and those signed in are signed out), or tick
  **rights switched off in this tenant**: nobody working in it gets them, whatever their groups, its administrators
  and server administrators included. Rights the server's configuration switches off are shown ticked and can't be
  changed here.
- **Delete:** removes the tenant with its libraries, accounts, groups and settings. Type its name to confirm.
