# Settings

The administration sets defaults at a **level**: the whole server (every tenant) and this tenant (its libraries and
accounts) under **Tenant and server › Settings**, one library under **Libraries › Library settings**. Each person's own preferences, in [My account](../user-guide/account.md), come last. How
the levels combine: [settings levels](../reference/settings-levels.md).

Open the level's page (for a library, choose it at the top), then for each setting:

- the value at this level, with where the value in effect comes from (**Set at this level**, or **From** a level
  above or the default);
- **Lock:** the levels below can't change it (a person's preference included);
- **Locked by a level above:** this level can't change it.

**Save** keeps the changes, **Discard** forgets them. Each level needs its right: server settings, tenant settings or
library settings ([rights](../reference/rights.md)).
