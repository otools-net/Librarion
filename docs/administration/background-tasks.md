# Background tasks

**Administration › Background tasks** (with the scan right) shows what the server does by itself or on request, in
every library you may scan. It has three pages:

- **Tasks:** a line on what runs now and what comes next, then a card for **Folder scan** and one for **Import** (with
  the import right). Each card says whether it is idle or running (and for how long), shows a running task's progress
  (the books found so far and the file being read, with **Cancel**), its **last run** (how it ended, when, in which
  library: it opens the history) and its **next run** (the schedule coming due first). **Run now** scans the library
  chosen on the card; **Start an import** opens that library's Import page; **Schedules** opens the next page.
- **Schedules:** each library's schedules under its name, added and changed as on the library's own Schedules tab.
- **History:** every library's runs, newest first: what each did, how it ended, how long it took; **Older runs** shows
  more.

## The progress panel

While a scan, an import or a removal runs, a panel under the top bar shows it on every page: what runs and where
("Scanning Comics…"), the time it has taken, what it found so far and the file being read, with **Cancel**. Tasks
started by schedules or by other administrators show too. Tagging every book of a big list (**Tag all**, see
[Browsing](../user-guide/browsing.md#selecting-and-tagging-books)) shows there too, also to those who tag books in
that library without scanning it; they may cancel it. When a task ends, the panel shows how it went until you close
it (×), and a short message says so.
